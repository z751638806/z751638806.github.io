你在手机上打开本站？

  1. 把 peipeidev.cn 复制到电脑浏览器打开，固件与额度都不绑设备，换浏览器不影响。

使用说明

三步完成刷写，无需安装任何软件

串口能力内置于浏览器 · 用 Chrome / Edge 打开本页即可

无设备演示
1准备

电脑装 Chrome 或 Edge；备一根可靠的数据线（"连不上"多半是它）；开发板通电。

2选设备与固件

「刷固件」页选设备类型与固件；面板里会显示刷写后的热点、密码与使用说明。

3连接并刷写

浏览器弹窗中选中串口；提示手动操作时按住 BURN → 短按 RST → 松开。完成自动复位。

演示与真实刷写流程完全一致，只是不连真板——建议新用户先跑一遍熟悉交互；救砖演练在演示页地址后加 &rescuebins=bw16-01。

串口驱动（插上板子没有串口出现时看这里）

大多数情况不需要装：ESP32-C3/S3 原生 USB、BW16 原生 USB 全系统免驱；Windows 10/11 插上 CH340/CP210x 板子会自动通过 Windows Update 装好（联网等几秒）；Linux 全免装。需要手动装的主要是 macOS + CH340/CP210x 板的组合。

驱动下载（厂商官网）：

· CH340 / CH341（最常见，BW16-Kit 与多数 ESP8266/ESP32 板）： Windows 安装包（WCH 官网） · macOS 驱动（WCH 官网）

· CP210x（部分 ESP32/ESP8266 板）： Silicon Labs 官网 VCP 驱动（Win/mac）

· 串口连接排错参考：Espressif 官方文档

检测到你在 macOS：如果你用的是 CH340 / CP210x 板，请先装上方对应驱动再回来刷写（装一次长期有效）；C3/S3 原生 USB 与 BW16 原生 USB 无需此步。

常见问题

提示"当前浏览器不支持 Web Serial"

换 Chrome / Edge 打开本页。

连不上 / 反复失败

① 换一根数据线、直插电脑（不要经 USB hub）；② 关闭占用串口的其他程序（串口监视器 / 上位机）；③ 按提示手动 BURN + RST 后重试；④ 刷新页面再试。

刷完设备没反应

按一下板上 RST 键，或重新插拔 USB 供电。

手机上打开本站？

手机浏览器没有串口权限，把网址发到电脑上用 Chrome / Edge 打开。

固件需要激活？

带「需激活」字样的固件按面板说明操作（设备码 → 获取激活码 → 设备端激活）；其余刷完即用。
